hey hey,  
this is my little pure python ray tracer  
it uses pygame to show the rendered frames.  
  
to run it you will need pygame and numpy.  
to install pygame run:  
`pip install pygame`  
to install numpy run:  
`pip install numpy`  
  
then just run it with:  
`python main.py`  
or  
`python3 main.py`
